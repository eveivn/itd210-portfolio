# itd210-portfolio
# Portfolio Website — Evelyn Garcia

## About This Project
This portfolio website showcases artwork created by an illustration team that focuses on publishing web comics and digital art. The main objective is to present the artwork following responsive web design principles that can be accessible on any device. 

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Responsive Design)
- JavaScript
- Tailwind CSS

## Course
ITD 210 Web Development — Northern Virginia Community College

#
- What is the strongest part of your final site and why?

The strongest parts of my site is the use of a consistent color palette and the use of white/negative space. I spaced sections out so as to not overwhelm the user with big blocks of text and images all at once, added reveal scrolling for the same reasons. The absolute strongest part of this project is the use of original artwork to convey a story. These pieces of art make the site feel alive and worth scrolling.

- What did you learn about responsive design and interactivity this semester?

The more I added responsive media queries, the more I got the hang of it and understood what was happening. I realized how important responsive design is to a website now that most people have multiple ways of consuming media. 

- Which piece of feedback changed your approach the most?

The playground page helped and inspired me the most. It showed that there were so many options to choose from, and that a site has endless ways of turning out depending on how you style it. Responsive design was my biggest push to repolish the site so there would be no major issues on mobile.

- If you had another month, what would you add or refine next?

I would add more visual interest, such as color to the text, add eyebrows etc. I would also refine media queries and tweak them to make them even more responsive. Additionally, I’d love to make the gallery clickable and interactive. There’s a lot I will continue to do to make the site overall better for the art and user.
